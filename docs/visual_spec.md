# Visual specification

## Evidence-backed direction
- Fast, readable 2D platforming; exit-oriented stages and traps.
- A compact, characterful protagonist; the review describes a pudgy bee-like hero.
- Retro-game sensibility and distinct worlds are mentioned by the official page.
- Exact pixel dimensions, native viewport, menu typography, animation frame counts, and original HUD measurements could not be verified from the text-only references inspected so far.

## Original replacement-art direction
- Internal viewport: 960 × 540, landscape.
- Palette: dusky indigo background, muted purple terrain, mint top-edge highlights, warm yellow protagonist/collectibles, coral hazards.
- Terrain: chunky slab silhouettes with repeated small tile marks; high contrast at platform edges.
- Player: original tiny yellow adventurer silhouette with pale face, dark feet, mint rear accent; procedural drawing is a placeholder for a future authored sprite sheet.
- Hazards: coral triangular spikes with light edge highlights.
- Collectibles: animated golden motes with bobbing and small glints.
- UI: restrained dark panel, compact HUD, translucent touch controls. These are original design choices, not claimed to match the original menus exactly.
- Rendering: Godot 2D GL Compatibility renderer; no remote assets, fonts, APIs, analytics, ads, or network dependency.

## Art production follow-up
Replace procedural draw nodes with original sprite sheets only after comparing the actual screenshots at full resolution. Preserve silhouette readability, collision origins, nearest-neighbour scaling, and a consistent pixel grid.
